MCE — Morphological Computation Engine

Browser-first Finnish NLP engine. Runs entirely in WASM — no server, no network, no GPU required.

What is MCE?

MCE (Morphological Computation Engine) is a Rust-native Finnish NLP engine designed for browser deployment via WebAssembly. It provides morphological analysis, spell checking, grammar checking, hyphenation, POS tagging with disambiguation, and morphological generation — all running client-side with zero server dependencies.

Key Features

  • Complete offline operation — WASM + dictionary loaded once, works without network
  • VFST dictionary format — Succinct trie with LOUDS encoding for compact storage
  • Comonadic architecture — Writer comonad for composable morphophonological rules
  • Viterbi disambiguation — Weighted lattice + suffix tagger for 94.66% UPOS accuracy (UD Finnish-TDT dev)
  • CG rules — 62 active constraint grammar rules for context-sensitive disambiguation
  • Morphological generation — Noun declension (22 forms: 11 sg + 11 pl) + verb conjugation (4 types, beta)
  • Grammar checking — 21 rules for common Finnish writing errors
  • 22 WASM API methods — Complete JS/TS API with full TypeScript types

Spell Check

spell_check()

The foundation for red-underline spell checking in editors and word processors. Finnish cannot rely on simple dictionary lookup because every noun has dozens of inflected forms and words combine freely into compounds. MCE performs morphological analysis to verify that a word follows valid Finnish morphophonological patterns, even if the exact surface form is not stored in the dictionary.

koira rautatieasema juoksemassa koirra asdfgh
Check

Morphological Analysis

analyze()

The core of every NLP task. A single Finnish word can have thousands of inflected forms — koira (dog) alone produces 22 case×number combinations, each potentially compounding further. This function returns every possible morphological reading of a word: base form (lemma), word class, case, number, person, and other features. Multiple readings indicate genuine ambiguity that context must resolve.

kissalla tuli rautatieasemalta xyzzy
Analyze

POS Tagging

analyze_sentence()

The backbone of translation engines, grammar checkers, and reading assistants. POS tagging determines whether each word is a noun, verb, adjective, etc. In Finnish, words like kuusi can mean ‘six’ (NUM), ‘spruce tree’ (NOUN), or ‘your moon’ (NOUN) — only context resolves the ambiguity. MCE runs the full pipeline: tokenize → FST analysis → CG rules → suffix tagger → Viterbi, achieving 94.66% UPOS accuracy on the UD Finnish-TDT dev split.

Hyphenation

hyphenate()

Essential for typesetting and responsive text layout. Finnish compound words can be extremely long — lentokonesuihkuturbiinimoottori (jet turbine engine) is 33 characters — and without proper hyphenation, text overflows columns and narrow screens. MCE splits words at valid break points using syllable rules and compound boundaries, the same way Finnish typographers do.

kissanpentu yliopisto Long compound Derived word

Grammar Check

grammar_check()

Goes beyond spell checking: even correctly spelled words can form grammatically wrong sentences. MCE detects 21 types of grammar errors including repeated words, missing sentence capitalization, incorrect spacing around punctuation, and more. Each error comes with a position, type, and suggested fix — ready for red/green squiggly underlines in an editor.

Repeated word Correct sentence Capitalization

Spelling Suggestions

suggest()

Powers the “Did you mean…?” feature in editors. When a word fails spell check, MCE searches a 44K-word dictionary using trie-based fuzzy matching to find similar real words, ranked by edit distance. All suggestions are guaranteed dictionary forms, so the user can click to fix with confidence. The search auto-escalates edit distance (up to 3) if no close matches exist.

koirra Helsigni ksia
Suggest

Compound Word Split

compound_split()

Reveals the internal structure of Finnish compound words. Unlike English, where “train station” is two words, Finnish writes it as one: rautatieasema. Speakers create new compounds freely by concatenation, producing words that no dictionary could exhaustively list. MCE’s Pushdown Transducer (M3) decomposes these compounds into their meaningful parts, enabling search indexing, machine translation, and vocabulary learning tools.

rautatieasema Jet engine kissanpentu koira (simple)
Split

Paradigm Generation

generate_paradigm()

Ideal for language learning apps, dictionary tools, and flashcard generators. Finnish nouns inflect across 11 grammatical cases in both singular and plural, yielding 22 forms per word. The generation pipeline applies consonant gradation (e.g., pp→p in kauppa→kaupan) and vowel harmony (front vs. back suffixes) automatically through the Writer Comonad.

koira kauppa (gradation) pöytä (harmony)
Generate

Verb Paradigm

generate_verb_paradigm()Beta

Generates the full conjugation paradigm of a Finnish verb across present, past, conditional, and negative tenses. Finnish has four main verb conjugation types determined by the infinitive ending, and MCE handles regular verbs from all four types. This feature is in beta — regular verbs produce correct forms, but irregular verbs (such as olla) may generate incorrect conjugations.

puhua (type 1) lukea (type 1) tulla (type 3) haluta (type 4) olla (irregular)

API Reference

All 22 WASM-exported methods on MceEngine.

Initialization

MceEngine.load(mor_vfst: Uint8Array): MceEngine

Create an engine by loading a VFST dictionary binary. Throws on invalid data.

Static constructor. Returns a new MceEngine instance.

engine.load_model(data: Uint8Array): void

Load a suffix tagger model for POS disambiguation. Improves UPOS from 83.92% (rule-only) to 94.66% on UD Finnish-TDT dev. Throws if data is not a valid MCET model.

engine.has_model(): boolean

Check whether a suffix tagger model is loaded.

engine.load_wordlist(data: Uint8Array): void

Load a wordlist for trie-based spelling suggestions. Accepts plain text (one word per line) or TSV format (lemma_dict.tsv). When loaded, suggest() uses fast fuzzy trie search instead of edit-distance fallback. Throws if data cannot be parsed as a valid wordlist.

engine.has_wordlist(): boolean

Check whether a wordlist (spelling suggestion trie) is loaded.

MceEngine.version(): string

Return the MCE version string (e.g., "0.1.0").

Single-Word Analysis

engine.analyze(word: string): string

Morphological analysis of a single word. Returns JSON array of analysis objects with BASEFORM, CLASS, and morphological features.

engine.get_baseform(word: string): string

Get the base form (lemma) of a word. Returns the first available base form or the input word.

engine.spell_check(word: string): boolean

Check if a word is correctly spelled. Uses morphological analysis and compound-aware checking — more permissive than is_valid_word() for compound words.

engine.is_valid_word(word: string): boolean

Check if a word has a valid morphological analysis in the VFST dictionary. Pure linguistic check -- does not use spelling suggestion trie or cache.

engine.suggest(word: string, max_edits: number): string

Generate spelling suggestions using trie-based fuzzy search against a 44K-word dictionary. All candidates are known dictionary forms, ranked by edit distance. Auto-escalates distance if no results (up to 3). Without a wordlist, falls back to suggest_with_context(), which generates candidates via edit-distance and validates them through morphological analysis (candidates are not guaranteed to be dictionary forms). Returns JSON array of up to 10 suggestions.

engine.suggest_with_context(word: string, prev_word: string, max_edits: number): string

Context-aware suggestions using the previous word for better ranking.

engine.compound_split(word: string): string

Split a compound word into its components. Returns JSON array of component parts.

Sentence-Level Analysis

engine.analyze_sentence(text: string): string

Full sentence analysis with tokenization, POS tagging, and disambiguation. Returns JSON with CoNLL-U-style token objects.

engine.disambiguate_sentence(text: string): string

Sentence disambiguation returning the best analysis for each token (Viterbi + CG). Returns JSON array of disambiguated tokens.

engine.grammar_check(text: string): string

Check text for grammar errors. Returns JSON array of error objects with position, length, description, and suggestions.

Hyphenation

engine.hyphenate(word: string): string

Hyphenate a single word. Returns the word with hyphens inserted at valid break points.

engine.hyphenate_text(text: string): string

Hyphenate all words in a text, preserving whitespace and punctuation.

Morphological Generation

engine.generate_form(baseform: string, case: string, number: string): string

Generate a specific inflected form. Case: "nominative", "genitive", "partitive", etc. Number: "singular" or "plural".

engine.generate_paradigm(baseform: string): string

Generate all 22 case forms of a noun (11 singular + 11 plural). Returns a JSON array of {"case":"nominative sg","form":"..."} objects. Labels include number suffix (e.g., "genitive sg", "partitive pl").

engine.generate_verb_form(baseform: string, tense: string, person: string, polarity: string): string

Beta. Generate a specific verb form. Tense: "present", "past", or "conditional". Person includes number (e.g., "1sg", "2sg", "3sg", "1pl", "2pl", "3pl"). Polarity: "affirmative" or "negative". Regular verbs (puhua, lukea, antaa, tulla, haluta) work correctly; irregular verbs (olla, syoda, juosta) may produce incorrect forms.

engine.generate_verb_paradigm(baseform: string): string

Beta. Generate the full verb conjugation paradigm. Returns a JSON array of {"label":"...","form":"..."} objects covering present, past, conditional, and negative present tenses. Regular verbs work correctly; irregular verbs may produce incorrect forms.

Getting Started

Build, install, and use MCE.

Prerequisites

  • Rust toolchain (stable, 1.86+)
  • wasm-pack for WASM builds
  • Node.js 18+ (for npm package / docs site)

Build from Source

# Clone the repository git clone https://github.com/yongsk0066/mce.git cd mce # Run all tests cargo test --all-features # Build WASM package wasm-pack build crates/mce-wasm --target web --release # Check code quality cargo fmt --all --check cargo clippy --all-features -- -D warnings

CLI Usage

# Build the CLI cargo build --release -p mce-cli # Analyze a word ./target/release/mce-cli analyze koira # Spell check ./target/release/mce-cli spell koirra # Full sentence analysis echo "Koira juoksee nopeasti." | ./target/release/mce-cli sentence

JavaScript / WASM Usage

import init, { MceEngine } from './mce_wasm.js'; // Initialize WASM await init(); // Load dictionary const dictBytes = await fetch('mor.vfst').then(r => r.arrayBuffer()); const engine = MceEngine.load(new Uint8Array(dictBytes)); // Optional: load suffix tagger model for better POS accuracy const modelBytes = await fetch('suffix_tagger.bin').then(r => r.arrayBuffer()); engine.load_model(new Uint8Array(modelBytes)); // Spell check console.log(engine.spell_check('koira')); // true console.log(engine.spell_check('koirra')); // false // Morphological analysis console.log(engine.analyze('kissalla')); // JSON array // Full sentence POS tagging console.log(engine.analyze_sentence('Koira juoksee nopeasti.')); // Suggestions for misspelled words console.log(engine.suggest('koirra', 1)); // JSON array // Hyphenation console.log(engine.hyphenate('suomalainen')); // "suo-ma-lai-nen" // Grammar checking console.log(engine.grammar_check('koira koira juoksee.')); // Compound word splitting console.log(engine.compound_split('rautatieasema')); // Generate noun paradigm console.log(engine.generate_paradigm('koira'));
